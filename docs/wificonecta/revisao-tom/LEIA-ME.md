# Revisão de linguagem: preparação local

Os quatro arquivos `.diff` sem o sufixo `-proposta` mostram ajustes aplicados aos rascunhos existentes no banco isolado pelo editor Tiptap. As versões HTML e JSON correspondentes também estão nesta pasta.

Os quatro arquivos `-proposta.diff` são sugestões feitas sobre snapshots locais dos demais artigos publicados. Eles não foram importados para o editor. Antes de qualquer aplicação, é necessário conferir os registros atuais no CMS e aplicar as alterações pelo editor isolado, mantendo HTML e JSON sincronizados.

Nenhuma versão foi publicada. A revisão não inclui `/wifi-e-fibra`.
