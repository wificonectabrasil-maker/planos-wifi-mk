# Checklist de instalação

1. Dependências instaladas.
2. URL/token Turso configurados somente no servidor.
3. db:migrate e db:verify executados.
4. E-mail, senha e segredo de sessão próprios.
5. Identidade, fontes e políticas revisadas.
6. Silos e artigos novos criados no admin.
7. test:database, testes de navegador e build verificados.
8. Variáveis do deploy e SITE_URL definidos.
9. Indexação habilitada quando o conteúdo estiver pronto.
