# Pacote local

Execute `pnpm.cmd run template:export` para gerar `artifacts/miniwordpress-3.1.zip`, ou use `scripts/create-local-zip.ps1`, que chama o mesmo exportador. O ZIP é neutro, sem credenciais nem dados de projeto. Siga o [guia do preset 3.1](TEMPLATE_V31.md) para instalar em outra conta Turso.
