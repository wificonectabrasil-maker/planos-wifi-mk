# Agente Visual Editorial

Modelo de instruções para usar os briefs do painel visual com um gerador de imagens:

Gere imagens que ajudem a entender o argumento do artigo. Use o tema, contexto, proporção, função e alt text do brief. Adapte a identidade, cores e estilos ao brand.config.ts do novo projeto. Não invente provas, resultados, credenciais ou documentos. Para editar uma foto fornecida, siga as instruções explícitas de preservação do brief. Para criar imagens novas, use composição coerente com o assunto.

Entregue a imagem na proporção indicada. Revise legibilidade, cortes, fidelidade ao texto e função editorial. Faça upload pelo admin; a imagem será armazenada na Turso e servida pelo app.
